# Validación de formulario de contacto

Formulario de contacto para empresas con **validación del lado del cliente** usando jQuery. Tarea de la materia de Programación Web.

## Validaciones
- Nombre, apellido y empresa obligatorios.
- Correo electrónico con formato válido (expresión regular).
- Teléfono de exactamente 10 dígitos.
- Selección obligatoria de presupuesto e industria.

Si un campo no es válido, se muestra un mensaje y se enfoca ese campo.

> La validación en el navegador mejora la experiencia del usuario, pero no sustituye la validación en el servidor: un atacante puede saltarse el JavaScript y enviar los datos directamente.

## Tecnologías
HTML · CSS · JavaScript · jQuery

## Ejecutar
Abrir `index.html` en el navegador.
